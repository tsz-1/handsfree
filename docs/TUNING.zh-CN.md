# HandsFree 调试教程

调参只需要改 `config.yaml`，不用改代码。**改完配置要重启程序才会生效**（按 `q` 退出，再重新运行）。

## 0. 准备：用"只看不动"模式调试

```bash
source venv/bin/activate
python -m handsfree --dry-run
```

`--dry-run` 会正常识别手势、显示画面，但**不会真的控制鼠标**，同时在终端打印识别到的事件：

```
[  812.431] click
[  815.102] mouse_down
[  816.870] mouse_up
[  820.015] scroll +0.52
```

这样你可以放心地做各种手势，观察程序"以为"你在做什么，不用担心误点东西。调好之后再去掉 `--dry-run` 实际使用；如果想在实际使用时也看到事件，加 `--verbose`。

## 1. 看懂画面上的信息

| 画面元素 | 含义 |
| --- | --- |
| 紫色方框 | 操作区域，手指在框内移动对应整个屏幕 |
| `Mode` | 当前状态：`idle` 空闲、`pinch` 捏合中、`drag` 拖拽中、`right pinch` 右键捏合中、`scroll` 滚动中 |
| `L pinch` | 拇指尖到食指尖的距离，单位是"手掌长度"（手腕到中指根部） |
| `R pinch` | 拇指尖到中指尖的距离，单位同上 |
| `Index ext` / `Middle ext` | 食指尖 / 中指尖到手腕的距离，单位同上。伸直约 2，握拳约 1 |
| 拇指到指尖的连线 | 紫色 = 未捏合，绿色 = 已捏合 |
| 黄色横线和竖线 | 滚动模式下，横线是开始滚动时手指的位置，竖线是当前偏移 |
| `FPS` | 帧率，低于 20 时手感会明显变差 |

**为什么单位是"手掌长度"**：手离摄像头远，所有像素距离都会变小；除以手掌长度之后，同一个手势不管远近数值都差不多，所以一套阈值能适应不同距离。

## 2. 按顺序校准

建议按下面的顺序来，每一步都在 `--dry-run` 模式下进行。先观察数值，再改配置。

### 第 1 步：捏合阈值 `pinch_enter` / `pinch_exit`

1. 伸出食指做指向动作，拇指自然放松，记下 `L pinch` 的数值（一般在 0.6 以上）。
2. 拇指和食指捏紧，记下 `L pinch` 的数值（一般在 0.1–0.2）。
3. 把手移近、移远各试一次，看数值变化范围。

设置原则：

- `pinch_enter` 设成比"捏紧时的最大值"稍大一点，确保每次捏合都能识别。
- `pinch_exit` 设成比 `pinch_enter` 大 0.08–0.15，但要明显小于"放松时的数值"。
- 两者之间的差距就是"迟滞区"：数值在这个区间内来回抖动时，状态保持不变，不会一会儿捏合一会儿松开。

| 现象 | 调整 |
| --- | --- |
| 捏了但画面上连线不变绿 | 调大 `pinch_enter` |
| 手指还没碰到就触发了 | 调小 `pinch_enter` |
| 拖拽时会自己"断掉"（突然松开） | 调大 `pinch_exit` |
| 松开手指后要张得很开才能结束捏合 | 调小 `pinch_exit` |

### 第 2 步：握拳防误触 `min_finger_extension`

握拳时拇指会贴在食指旁边，`L pinch` 可能也很小，如果不加限制就会被当成点击。程序的做法是：只有食指（或中指）没有蜷起来时，才允许进入捏合状态。

1. 握拳，记下 `Index ext`（一般 0.8–1.1）。
2. 拇指和食指捏合，记下 `Index ext`（一般 1.4–1.7）。
3. 把 `min_finger_extension` 设在两者中间。

| 现象 | 调整 |
| --- | --- |
| 握拳会触发点击 | 调大 `min_finger_extension` |
| 正常捏合识别不了，但 `L pinch` 已经很小 | 调小 `min_finger_extension` |

### 第 3 步：右键

做拇指和中指捏合，观察 `R pinch` 和 `Middle ext`。右键用的是和左键同一组阈值，一般不用单独调整。

- **做指向动作时误触发右键**：看一下指向时 `R pinch` 是否过小。如果是，调大 `min_finger_extension`，或者调小 `pinch_enter`。
- **想点左键却出了右键**：程序会比较两个比例，哪个更小就算哪个。捏合时让中指离拇指远一点即可。

### 第 4 步：点击和拖拽的分界 `hold_s`

捏合后在 `hold_s` 秒内松开算点击，超过就算拖拽。

| 现象 | 调整 |
| --- | --- |
| 想点击却变成了拖拽（比如文字被选中） | 调大 `hold_s`，比如 0.4 |
| 拖拽要等很久才开始 | 调小 `hold_s`，比如 0.2 |

补充：拖拽开始后，手不移动直接松开，效果等同于一次点击，所以"慢慢点"也不会出错。

### 第 5 步：滚动 `scroll_deadzone` / `scroll_speed`

滚动的操作方式类似摇杆：伸出食指和中指（无名指、小指收起），**进入滚动模式时手指所在的位置就是"中点"**。往上移动就向上滚，偏离中点越远滚得越快，回到中点就停。

| 现象 | 调整 |
| --- | --- |
| 手没动页面却在慢慢滚 | 调大 `scroll_deadzone` |
| 要移很远才开始滚 | 调小 `scroll_deadzone` |
| 滚得太快或太慢 | 调整 `scroll_speed` |
| 滚动方向反了 | 把 `scroll_speed` 改成负数 |

### 第 6 步：光标手感（`mouse` 部分）

这部分在上一轮已经调过，这里汇总一下：

| 现象 | 调整 |
| --- | --- |
| 手静止时光标还在抖 | 调小 `min_cutoff`（如 0.3） |
| 快速移动时光标跟不上、有拖尾 | 调大 `beta`（如 0.01） |
| 点击位置总是偏一点 | 调大 `click_rewind_s`（如 0.2） |
| 手要移动很远才能到屏幕边缘 | 调大 `margin_x` / `margin_y` |
| 光标太灵敏，小按钮难点中 | 调小 `margin_x` / `margin_y`（操作框变大） |
| 手离开画面再回来，光标会滑过来 | 调小 `reset_after_s` |

`margin_x` 和 `margin_y` 调整时建议保持横纵放大倍数接近，否则横向和纵向移动手感不一致。放大倍数的计算方法：

```
横向放大倍数 = 屏幕宽度 / (摄像头宽度 × (1 - 2 × margin_x))
纵向放大倍数 = 屏幕高度 / (摄像头高度 × (1 - 2 × margin_y))
```

## 3. 常见问题

**终端提示找不到摄像头**
到"系统设置 → 隐私与安全性 → 摄像头"给终端 App 打开权限，然后完全退出终端再重新打开。也可以用 `--camera 1` 手动指定编号。

**光标能动但点击、拖拽、滚动没反应**
到"系统设置 → 隐私与安全性 → 辅助功能"给终端 App 打开权限。

**鼠标左键好像一直被按住**
程序退出时会自动松开按键；如果程序异常崩溃，用触控板或鼠标点一下即可恢复。

**拖拽能选中文字，但拖不动窗口**
确认你用的是最新代码。macOS 上必须发送专门的"拖拽"事件，程序在拖拽状态下已经这样处理了。

**帧率很低**
关闭其他占用摄像头或 CPU 的程序；也可以在 `config.yaml` 里把 `ui.show_window` 改成 `false`，不显示预览画面能省一些性能。

## 4. 如果你修改了代码

修改 `handsfree/` 下的代码后，先跑一遍测试，确认没有破坏已有的行为：

```bash
pytest -q
```

测试不需要摄像头：它用程序生成的"假手"模拟各种姿势（指向、捏合、握拳、双指等），验证状态机在每种情况下的输出是否正确。如果你改了阈值的默认值，部分测试可能需要跟着调整。
